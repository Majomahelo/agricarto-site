# AgriCarto

Application Android de cartographie des parcelles agricoles : cadastre, PAC, mesures, détection automatique des contours, tour de parcelle au GPS, coordonnées, captures et cartes hors ligne.

**Site :** voir la page de présentation (GitHub Pages de ce dépôt).

## Signaler un problème ou proposer une idée

Utilisez l'onglet **Issues** de ce dépôt (« New issue ») et choisissez le formulaire adapté. Indiquez la version de l'appli (menu ⋮ › À propos) et votre modèle de téléphone.

## Confidentialité

Pas de compte, pas de publicité, pas de traceur : vos données restent sur votre téléphone. Voir [la politique de confidentialité](confidentialite.html).
