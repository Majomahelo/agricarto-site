Politique de confidentialité

Application AgriCarto (Android). Dernière mise à jour : octobre 2026.

En résumé

AgriCarto ne demande aucun compte et ne contient ni publicité, ni traceur, ni statistique d'utilisation. Vos données restent sur votre téléphone. L'éditeur de l'application ne reçoit aucune de vos données.

Données enregistrées sur l'appareil

Vos parcelles, groupes, sauvegardes, préférences et cartes téléchargées sont enregistrés uniquement dans l'application, sur votre appareil. Ils ne sont copiés ailleurs que si vous le décidez :

  • dans le fichier de synchronisation que vous choisissez vous-même (votre Google Drive, Dropbox, OneDrive…) ;
  • dans les exports et les captures que vous enregistrez ou partagez.

Désinstaller l'application efface ces données de l'appareil.

Position GPS

La position est utilisée uniquement sur l'appareil, lorsque l'application est ouverte : pour l'afficher sur la carte, mesurer, faire le tour d'une parcelle ou donner les coordonnées d'un point. Elle n'est jamais transmise à l'éditeur ni à un tiers. L'autorisation peut être retirée à tout moment dans les réglages d'Android.

Détection automatique des contours

Le modèle d'intelligence artificielle est intégré à l'application et fonctionne entièrement sur l'appareil : aucune image n'est envoyée sur Internet.

Services en ligne interrogés

Pour afficher les cartes et certaines informations, l'application interroge directement des services publics. Comme pour tout site cartographique, ils reçoivent les coordonnées de la zone affichée ou du point touché, ou le texte tapé dans la recherche de lieu, mais aucune donnée personnelle :

  • Géoplateforme de l'IGN (data.geopf.fr) : photos aériennes, plan, cadastre, registre parcellaire graphique, BD Forêt, contours administratifs, recherche d'adresses ;
  • API Carto de l'IGN (apicarto.ign.fr) : informations d'une parcelle cadastrale ;
  • API Découpage administratif (geo.api.gouv.fr, État français) : recherche de communes ;
  • OpenStreetMap, uniquement si vous choisissez ce fond de carte ;
  • Google Maps, uniquement si vous touchez « Itinéraire » (les coordonnées de la parcelle sont alors ouvertes dans Google Maps).

Ces services appliquent leur propre politique de confidentialité.

Autorisations demandées

  • Accès à Internet : fonds de carte et services ci-dessus ;
  • Position (précise, pendant l'utilisation) : voir « Position GPS » ;
  • Fichiers : uniquement ceux que vous choisissez (import, export, synchronisation).

Enfants

L'application s'adresse à un public professionnel et adulte ; elle ne collecte aucune donnée, y compris d'enfants.

Vos droits

Aucune donnée personnelle n'étant collectée par l'éditeur, il n'y a rien à consulter ou à effacer de son côté. Vous pouvez à tout moment exporter vos données, les effacer de l'appareil (menu ⋮ › Effacer toutes les données), arrêter la synchronisation et supprimer le fichier de synchronisation de votre espace de stockage.
